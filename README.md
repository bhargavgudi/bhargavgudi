# Sai Bhargava Gudi — GitHub Pages Portfolio

Personal portfolio for **bhargavgudi**.

## Deploy

1. Create a GitHub repository named exactly `bhargavgudi.github.io`.
2. Upload all files from this folder to the repository root.
3. Upload your resume PDF and keep the filename:
   `Sai-Bhargava-Gudi-Resume-2026.pdf`
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Open: https://bhargavgudi.github.io

## Customize

- Edit `index.html` for content.
- Edit `style.css` for colors/layout.
- Edit `script.js` for interactions.
